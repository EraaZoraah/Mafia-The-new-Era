# 1.18.5 — login and registration artwork

A dark gradient fade supports the hero text; a dark translucent, gold-bordered card separates labels and inputs from the background. Inputs have brighter text and a clear focus outline. The welcome page and in-game banners retain their existing styling.

At the mobile breakpoint, the hero and form stack in one column while retaining a single non-repeating background. Browser checks at desktop size and 390px mobile width confirmed no repeated image and no horizontal overflow. Both login and registration were visually checked; the registration referral section and password field remain part of the existing form. No real login or registration was submitted during the isolated preview.

Eight targeted bot/guide/news checks passed. Controlled Dutch language coverage has zero missing items. This is a visual change: player actions, authentication handlers, bot strategies and Luca knowledge sources are unchanged. Push delivery remains paused.
